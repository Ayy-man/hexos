**1. CATEGORY_CONFIG map** — A single `Record<string, { icon: React.ElementType; colorClass: string; bgClass: string; dotClass: string; filterGroup: FilterCategory }>` mapping every known action string to its visual config. Import Lucide icons at the top: ArrowRightLeft, SquareCheck, TrendingUp, FileText, Paperclip, BadgeCheck, UserPlus, ClipboardCheck, MessageSquare, Circle. **5. Helper functions:**

- `toTitleCase(str: string): string` — Splits on spaces, capitalizes first letter of each word. Used for status label formatting.

- `getCategoryConfig(action: string)` — Returns `CATEGORY_CONFIG[action] ?? DEFAULT_CONFIG`. Single lookup point.

- `formatActivityDetail(action: string, details: Record<string, unknown> | null, projectId: string, requirements?: Array<{ id: string; title: string }>): React.ReactNode` — The main action-type dispatcher. Returns a React node with rich inline detail. Uses a switch on `action`:

  - `status_changed`: `toTitleCase(old_status.replace(/_/g, ' '))` arrow `toTitleCase(new_status.replace(/_/g, ' '))`. Font medium on new status.
  - `phase_changed`: Same pattern as status_changed (uses old_status/new_status or from/to fields).
  - `hill_position_updated`: Import `getZone` from `@/features/projects/components/hill-chart/utils`. Show `"title" oldPos% -> newPos%`. If `getZone(oldPos).zone !== getZone(newPos).zone`, append ` (OldZoneLabel -> NewZoneLabel)` in muted text. Handle missing old_position by falling back to `details.position`. Only show zone transition when both positions are valid and zones differ.
  - `deliverable_added`: Show `"title"` as a Link to `/projects/${projectId}?tab=deliverables`.
  - `deliverable_edited`: Show `"Updated: field1, field2"` from `fields_changed` array. If deliverable_id exists, make the intro a Link.
  - `deliverable_status_changed`: Show `"title"` as Link + ` old_status -> new_status` with toTitleCase.
  - `deliverable_deleted`: Show `"title"`.
  - `deliverable_completed`: Show `"title"` if available.
  - `document_created`: Show `"title"` as Link to `/projects/${projectId}?tab=deliverables` (documents are on gameplan; closest is deliverables tab or just show as text). Since there are no document sub-routes, render title as plain quoted text.
  - `document_deleted`: Show `"title"`.
  - `file_uploaded`: Show filename in `font-mono text-xs`. Show visibility in parentheses if present.
  - `file_deleted`: Show filename in `font-mono text-xs`.
  - `dev_assigned`: Show `dev_name` in font-medium.
  - `dev_unassigned`: Show `dev_name` if available.
  - `onboarding_requirement_completed`: Try to look up title via `requirements?.find(r => r.id === details.requirement_id)?.title`. If found, show `"title"`. Otherwise show "Requirement completed".
  - `note_added`: Show truncated preview (~60 chars) from `details.note`. If `details.deliverable_title` present, prefix with `on "deliverable_title": `.
  - `signoff_sent`, `signed_off`, `deliverables_confirmed`: No additional details (empty details). Return null.
  - `scope_change_flagged/approved/rejected`: Show entity name if in details.
  - Legacy `INSERT/UPDATE/DELETE/insert/update/delete`: Show `details.entity_name` if present, otherwise null.
  - `default`: Return null.

  Use nullish coalescing (`??`) everywhere to guard against missing fields. Use `String(details.field ?? '')` pattern.

  For entity links: Use `next/link` `<Link>` with `className="font-medium hover:underline"` and `onClick={(e) => e.stopPropagation()}`.

- `formatCompactDetail(action: string, details: Record<string, unknown> | null): string | null` — Returns a plain string (not React node) for the compact Recent Activity card in OverviewTab. Same logic as `formatActivityDetail` but simpler: no Links, no React elements, just text strings. Format: `"Entity Name"` or `old -> new` or truncated note preview. Returns null if no meaningful detail.

- `getDayLabel(date: Date): string` — Returns "Today", "Yesterday", or formatted date (`Month Day, Year` via `toLocaleDateString('en-US', { month: 'long', day: 'numeric', year: 'numeric' })`). Compare calendar dates, not timestamps.

- `groupByDay(entries: Array<{ created_at: string }>): Array<{ label: string; entries: typeof entries }>` — Groups a pre-sorted (descending) array of entries by calendar date. Returns `DayGroup[]` where each group has a `label` (from getDayLabel) and its `entries`.

- `formatExactTime(date: string): string` — For tooltip: `new Date(date).toLocaleDateString('en-US', { month: 'short', day: 'numeric', year: 'numeric', hour: '2-digit', minute: '2-digit' })`. Returns e.g. "Feb 28, 2026 at 3:42 PM" — note: use the object form that includes hour/minute.

- `formatRelativeTime(date: string): string` — Move the existing function from ActivityTab.tsx here. Same logic: Just now / Xm ago / Xh ago / Xd ago / formatted date for >7 days.

- `EMPTY_FILTER_MESSAGES: Record<FilterCategory, string>` — Contextual empty messages per filter: `{ all: 'No activity recorded yet', status: 'No status changes recorded', deliverables: 'No deliverable activity yet', documents: 'No document activity yet', hill_chart: 'No progress updates yet', files: 'No file activity yet', team: 'No team changes yet' }`.

**Important:** This file must NOT import from ActivityTab.tsx or OverviewTab.tsx (would create circular deps). It only imports from: `lucide-react`, `next/link`, `@/features/projects/components/hill-chart/utils`, and React.
