5. **Update the Recent Activity card section** (lines ~425-456). Replace the entire `{recentActivity.length > 0 && (<Card>...` block with:

```tsx
{/* Recent Activity */}
<Card>
  <CardHeader className="pb-2">
    <CardTitle className="text-sm font-medium flex items-center gap-2">
      <Activity className="h-4 w-4" />
      Recent Activity
    </CardTitle>
  </CardHeader>
  <CardContent>
    {recentActivity.length > 0 ? (
      <>
        <ul className="space-y-3">
          {recentActivity.map((activity) => {
            const config = getCategoryConfig(activity.action)
            const detail = formatCompactDetail(activity.action, activity.details)
            return (
              <li key={activity.id} className="flex items-center justify-between gap-4 text-sm">
                <div className="flex items-center gap-2 min-w-0">
                  {/* Colored category dot */}
                  <div className={cn('h-2 w-2 rounded-full shrink-0', config.dotClass)} />
                  <div className="min-w-0 truncate">
                    <span className="font-medium">
                      {ACTIVITY_LABELS[activity.action] || activity.action.replace(/_/g, ' ')}
                    </span>
                    {detail && (
                      <span className="text-muted-foreground"> — {detail}</span>
                    )}
                  </div>
                </div>
                <span className="text-xs text-muted-foreground whitespace-nowrap shrink-0">
                  {formatRelativeTime(activity.created_at)}
                </span>
              </li>
            )
          })}
        </ul>
        {/* View all activity link */}
        {onNavigateToActivity && (
          <div className="pt-3 mt-3 border-t border-border">
            <button
              onClick={onNavigateToActivity}
              className="text-xs text-muted-foreground hover:text-foreground transition-colors"
            >
              View all activity →
            </button>
          </div>
        )}
      </>
    ) : (
      <p className="text-sm text-muted-foreground text-center py-4">
        Activity will appear here as your project progresses
      </p>
    )}
  </CardContent>
</Card>
```

- **Compact detail inline** with em dash separator: `"Status changed — In Progress → Review"`
- **No "by user" line** — removed per CONTEXT.md decision (compact view doesn't show attribution)
- **"View all activity" link** at bottom with border-top separator
- **Empty state** shown when zero activity (card is always rendered now, not conditionally hidden)
- Activity entry uses `items-center` instead of `items-start` for better dot alignment with single-line entries
