Create a DB trigger on the `message_mentions` table that fires on INSERT and creates a notification for the mentioned user. The trigger is preferred over application-level code because mentions are created from multiple code paths.

**Migration file:**

```sql
-- @mention notification trigger
-- When a user is mentioned in a conversation message, create a notification

CREATE OR REPLACE FUNCTION notify_mention()
RETURNS TRIGGER AS $$
DECLARE
  v_message RECORD;
  v_actor_name TEXT;
  v_project_id UUID;
BEGIN
  -- Get the message details
  SELECT m.content, m.sender_id, c.project_id
  INTO v_message
  FROM messages m
  JOIN conversations c ON c.id = m.conversation_id
  WHERE m.id = NEW.message_id;

  -- Don't notify if user mentions themselves
  IF v_message.sender_id = NEW.mentioned_user_id THEN
    RETURN NEW;
  END IF;

  -- Get actor name
  SELECT name INTO v_actor_name
  FROM profiles
  WHERE id = v_message.sender_id;

  -- Create notification
  INSERT INTO notifications (user_id, type, title, message, project_id, actor_id)
  VALUES (
    NEW.mentioned_user_id,
    'mention',
    COALESCE(v_actor_name, 'Someone') || ' mentioned you',
    LEFT(v_message.content, 200),
    v_message.project_id,
    v_message.sender_id
  );

  RETURN NEW;
END;
$$ LANGUAGE plpgsql SECURITY DEFINER;
```

Add the trigger:
```sql
DROP TRIGGER IF EXISTS mention_notify ON message_mentions;
CREATE TRIGGER mention_notify
  AFTER INSERT ON message_mentions
  FOR EACH ROW
  EXECUTE FUNCTION notify_mention();
```

Verify the `message_mentions` table structure first by reading `supabase/migrations/20260103000001_conversations_system.sql` for column names. The trigger should reference the correct column names (likely `message_id`, `mentioned_user_id` or similar). If the columns are named differently, adjust accordingly.

Note: This trigger uses raw INSERT (not createNotification) which means push notifications won't fire. This is acceptable for V1 — the in-app notification and realtime subscription will still work. Push for mentions can be added later via a Supabase Edge Function if needed.
