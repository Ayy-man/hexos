**1. Create lib/api/project-improvements.ts:**

Follow manual type definition pattern.

```typescript
import { createClient } from '@/lib/supabase/server'

export type ImprovementPriority = 'nice_to_have' | 'important' | 'critical'
export type ImprovementStatus = 'open' | 'converted'

export interface ProjectImprovement {
  id: string
  project_id: string
  title: string
  description: string | null
  priority: ImprovementPriority
  status: ImprovementStatus
  converted_project_id: string | null
  added_by: string
  created_at: string
  author?: {
    id: string
    name: string
  }
  converted_project?: {
    id: string
    project_name: string
  } | null
}

export interface CreateImprovementInput {
  projectId: string
  title: string
  description?: string
  priority?: ImprovementPriority
}
```

Functions:

- `getProjectImprovements(projectId: string)`: Fetch all improvements for a project. Join with profiles for author name. Join with projects for converted_project_name (when status is 'converted'). Order by: status ASC (open first), then priority (critical, important, nice_to_have), then created_at DESC. Return `ProjectImprovement[]`.

- `createImprovement(input: CreateImprovementInput)`: Insert new improvement. Use current user for `added_by`. Return created record.

- `updateImprovement(id: string, input: { title?: string, description?: string, priority?: ImprovementPriority })`: Update improvement fields. Return updated record.

- `markAsConverted(improvementIds: string[], convertedProjectId: string)`: Batch update improvements to status='converted' and set converted_project_id. Use `.in('id', improvementIds)`.

- `getImprovementCounts(projectId: string)`: Return `{ open: number, converted: number, total: number }`.

**2. Create features/projects/actions/improvementActions.ts:**

`'use server'` directive.

Actions:

- `createImprovementAction(params: { projectId: string, title: string, description?: string, priority?: ImprovementPriority })`:
  - Call `createImprovement(params)`
  - `revalidatePath(/projects/${params.projectId})`
  - Return `{ data: improvement }` or `{ error: string }`

- `updateImprovementAction(params: { id: string, projectId: string, title?: string, description?: string, priority?: ImprovementPriority })`:
  - Call `updateImprovement(params.id, { title, description, priority })`
  - `revalidatePath(/projects/${params.projectId})`
  - Return `{ data: improvement }` or `{ error: string }`

- `convertToProjectAction(params: { projectId: string, improvementIds: string[], newProjectName: string, clientName: string })`:
  - This is admin-only. Create a new project using `createProject({ project_name: params.newProjectName, client_name: params.clientName, notes: 'Created from future improvements' })`.
  - Then call `markAsConverted(params.improvementIds, newProject.id)`
  - `revalidatePath(/projects/${params.projectId})`
  - `revalidatePath('/projects')`
  - Return `{ data: { projectId: newProject.id } }` or `{ error: string }`

All follow structured result pattern.
