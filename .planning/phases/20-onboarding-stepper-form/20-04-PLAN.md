**3. Create `CategoryEditor.tsx`:**

The admin view inside the category sheet. Shows questions in an editable, sortable list with "+ Add Question" at the bottom.

Props: `projectId: string`, `categoryId: string`, `questions: OnboardingQuestion[]`, `answers: OnboardingAnswer[]`

Structure:
```tsx
<div className="space-y-4">
  {/* Sortable question list */}
  <Sortable
    items={sortedQuestions.map(q => ({ id: q.id }))}
    onReorder={(newOrder) => {
      // Build position updates from new order
      const updates = newOrder.map((item, index) => ({
        id: item.id,
        position: index,
      }))
      startTransition(async () => {
        await reorderQuestionsAction(projectId, updates)
      })
    }}
  >
    {sortedQuestions.map((q, index) => (
      <SortableItem key={q.id} id={q.id}>
        <QuestionEditor
          question={q}
          projectId={projectId}
          onUpdate={handleQuestionUpdate}
          onDelete={handleQuestionDelete}
          onMoveUp={() => moveQuestion(index, -1)}
          onMoveDown={() => moveQuestion(index, 1)}
          isFirst={index === 0}
          isLast={index === sortedQuestions.length - 1}
        />
      </SortableItem>
    ))}
  </Sortable>

  {/* Inline question creation */}
  {showNewRow ? (
    <InlineQuestionRow
      onSave={handleAddQuestion}
      onCancel={() => setShowNewRow(false)}
    />
  ) : (
    <Button
      variant="ghost"
      size="sm"
      className="w-full border border-dashed"
      onClick={() => setShowNewRow(true)}
    >
      + Add Question
    </Button>
  )}
</div>
```

`handleAddQuestion` calls `addQuestionAction(projectId, categoryId, data)`, then `setShowNewRow(false)`. On error, show toast.

`handleQuestionUpdate` calls `updateQuestionAction(questionId, input)`.

`handleQuestionDelete` shows a small inline confirmation (not a dialog — just a "Are you sure?" with Yes/Cancel buttons replacing the delete button momentarily). On confirm, calls `deleteQuestionAction(questionId, projectId)`.

For accessible reorder fallback, `moveQuestion(index, direction)` swaps positions and calls `reorderQuestionsAction`.

Also show each question's existing answer (if any) in a muted preview below the question — so admin can see what DFY has answered while editing the form structure.
