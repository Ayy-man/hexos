`handleMarkComplete`:
```typescript
const handleMarkComplete = async () => {
  setIsMarkingComplete(true)
  try {
    const result = await markOnboardingCompleteAction(project.id)
    if (result.success) {
      toast.success('Onboarding marked as complete!')
    } else if (result.error === 'incomplete' && result.incompleteCategories) {
      // Flag the cards with issues
      setFlaggedCategories(result.incompleteCategories)
      toast.error('Some required items are incomplete. Please review the flagged sections.')
    } else {
      toast.error(result.error || 'Failed to complete onboarding')
    }
  } catch {
    toast.error('Failed to complete onboarding')
  } finally {
    setIsMarkingComplete(false)
  }
}
```

When `flaggedCategories` is set, each category card checks if its ID is in the list and shows a visual flag:
- On the card: a small warning icon + "Incomplete required items" text in `text-[--signal-warn]`
- Opening a flagged card: the sheet auto-scrolls to the first incomplete required field
