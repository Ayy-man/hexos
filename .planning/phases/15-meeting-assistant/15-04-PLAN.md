**lib/api/meeting-tasks.ts** — Following lib/api/invoices.ts pattern with admin client:

1. **getMeetingTasks(filters?)** — List tasks with optional filters: meeting_id, project_id, inquiry_id, status, assigned_to (profile uuid), due_before (date string), source, limit. Order by created_at desc. Also join meeting title (meetings.title) for context. Return `MeetingTask[]` (extended with meeting_title field).

2. **getMeetingTask(id)** — Get single task. Return `MeetingTask | null`.

3. **createMeetingTask(input: CreateMeetingTaskInput, userId: string)** — Create task with source 'manual', created_by = userId. Return `{success, data?, error?}`.

4. **updateMeetingTask(id, input: UpdateMeetingTaskInput)** — Update task fields. If status changes to 'done', set completed_at. If status changes from 'done', clear completed_at. Update updated_at. Return `{success, error?}`.

5. **deleteMeetingTask(id)** — Delete task. Return `{success, error?}`.

6. **convertTaskToDeliverable(taskId, projectId)** — Convert task to deliverable:
   - Get the task
   - Insert into `deliverables` table: title = task.title, description = task.description, project_id = projectId, status = 'pending'
   - Update the meeting_task with deliverable_id = new deliverable ID, project_id = projectId
   - Return `{success, data: {deliverable_id, task_id}, error?}`

Use `createClient` from `@/lib/supabase/admin`.

**features/meetings/lib/csv-utils.ts** — Using papaparse (installed in plan 01):

1. **generateTasksCSV(tasks: MeetingTask[])** — Map tasks to CSV-friendly objects with columns: title, description, assigned_to, due_date, priority, status, source, meeting_title, created_at. Use `Papa.unparse(data)` to generate CSV string. Return string.

2. **parseTasksCSV(csvText: string)** — Parse CSV text using `Papa.parse(csvText, { header: true, skipEmptyLines: true, transformHeader: h => h.toLowerCase().trim() })`. Validate that 'title' column exists. For each row, validate:
   - title: required, non-empty string
   - priority: must be one of low/normal/high/urgent (default: 'normal')
   - status: must be one of pending/in_progress/done/cancelled (default: 'pending')
   - due_date: if present, must be valid ISO date string
   Return `{success: true, tasks: ParsedTask[]}` or `{success: false, error: string, errors?: string[]}` where errors array has per-row error messages.

Import `Papa from 'papaparse'` and types from `@/lib/types/meetings`.

Create the `features/meetings/lib/` directory if it doesn't exist.

Create 5 route files, all requiring auth:

**app/api/meeting-tasks/route.ts** (GET + POST):
- GET: Parse query params (meeting_id, project_id, status, assigned_to, due_before, source, limit). Call getMeetingTasks(filters). Return JSON.
- POST: Parse body as CreateMeetingTaskInput. Call createMeetingTask(input, userId). Return 201/400.

**app/api/meeting-tasks/[id]/route.ts** (GET + PATCH + DELETE):
- GET: Call getMeetingTask(id). Return 404 if null.
- PATCH: Parse body, call updateMeetingTask(id, input). Return result.
- DELETE: Call deleteMeetingTask(id). Return result.

**app/api/meeting-tasks/[id]/convert-to-deliverable/route.ts** (POST):
- Parse body {project_id}. Validate project_id is present.
- Call convertTaskToDeliverable(taskId, projectId).
- Return 201 with {deliverable_id, task_id} on success.

**app/api/meeting-tasks/export/route.ts** (GET):
- Parse same query params as list endpoint for filtering.
- Call getMeetingTasks(filters).
- Call generateTasksCSV(tasks) from `@/features/meetings/lib/csv-utils`.
- Return Response with:
  - Content-Type: 'text/csv'
  - Content-Disposition: `attachment; filename="meeting-tasks-${date}.csv"` where date is YYYY-MM-DD format
- Return the CSV string as body.

**app/api/meeting-tasks/import/route.ts** (POST):
- Parse multipart form data: `const formData = await req.formData()`, get 'file' field.
- Read file as text: `const csvText = await file.text()`
- Parse with parseTasksCSV(csvText).
- If parse fails, return 400 with error details.
- For each valid parsed task, create a meeting_task row with source='imported', created_by=userId.
- If query params include meeting_id or project_id, apply to all imported tasks.
- Match assigned_to names against profiles (best-effort ILIKE match).
- Return {imported: number, skipped: number, errors: string[]}.

All routes follow standard auth pattern: check user with createClient from @/lib/supabase/server.
