**Critical bug found and fixed this session (commit d5ecb3b):**
The /admin/blockers page was CRASHING with React error #301 (too many re-renders). Root cause: in BlockerSidebar.tsx, `blocker?.id` returns `undefined` when blocker is null, but `prevBlockerId` state initializes to `null`. Since `undefined !== null` is always true, the setState-during-render pattern ran on every render → infinite loop → page crash. Fix: normalize `blocker?.id ?? null` before comparison.

**This was the "can't click on blocker sidebar button" bug** — the entire page crashed before rendering any cards.
