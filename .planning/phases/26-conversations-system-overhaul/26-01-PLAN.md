# Plan 26-01: Nuke Inquiry Comments System

**Phase:** 26 — Conversations System Overhaul
**Goal:** Remove the entire inquiry comments feature — components, API, server actions, sync logic, and database table
**Estimated scope:** ~2000 lines removed across 12 files

---

## Why

The inquiry comments system is dead weight that:
1. Causes DFY 500 errors (RLS policy on `inquiry_comments` rejects inserts from non-submitting DFY users)
2. Adds complexity via bidirectional sync between messages and inquiry_comments
3. Is unused in practice — user decision: nuke now, revisit in hexOS 2.0
