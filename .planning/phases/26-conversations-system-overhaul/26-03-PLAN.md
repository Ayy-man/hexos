# Plan 26-03: Conversation List UX Polish

**Phase:** 26 — Conversations System Overhaul
**Goal:** Bold unread text, tiered indicators (dot vs badge), "You:" prefix, tiered timestamps, and better last message formatting
**Depends on:** 26-01 (comment sync removal), 26-02 (tab filtering)

---

## Why

Current conversation list treats every unread message with equal urgency (numeric badge). No visual distinction between "someone sent a message" and "you were @mentioned." Timestamps use verbose `formatDistanceToNow` ("about 2 hours ago") instead of compact tiered format. No "You:" prefix when current user was last sender.

### Task 5: Tiered timestamps

**File:** `features/conversations/components/ConversationItem.tsx`

Replace `formatDistanceToNow` (lines 57-59) with a tiered timestamp helper:

```tsx
import { format, isToday, isYesterday, isThisWeek, isThisYear } from 'date-fns'

function formatConversationTime(date: Date): string {
  if (isToday(date)) return format(date, 'h:mm a')          // "2:45 PM"
  if (isYesterday(date)) return 'Yesterday'                   // "Yesterday"
  if (isThisWeek(date)) return format(date, 'EEEE')          // "Tuesday"
  if (isThisYear(date)) return format(date, 'MMM d')         // "Mar 4"
  return format(date, 'M/d/yy')                              // "3/4/25"
}
```

Replace the timestamp rendering:

```tsx
const lastMessageTime = conversation.last_message?.created_at
  ? formatConversationTime(new Date(conversation.last_message.created_at))
  : null
```

This is more compact and matches WhatsApp/Telegram/Teams patterns.
