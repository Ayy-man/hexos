<task type="auto">
  <name>Task 1: Create bid server actions</name>
  <files>features/opportunities/actions/bidActions.ts</files>
  <action>
Create server actions for bid operations following the pattern in `features/inquiries/actions/deliverableActions.ts`.

Structure:
```typescript
'use server'

import { revalidatePath } from 'next/cache'
import {
  submitBid,
  withdrawBid,
  updateBidStatus,
  type BidStatus,
  type DevOpportunityBid,
} from '@/lib/api/bids'
```

Actions to implement:

1. **submitBidAction(params):**
   - Takes `{ opportunityId: string, proposedWeeks: number, proposedPrice?: number, coverMessage?: string }`
   - Calls `submitBid()` from API
   - Revalidates `/dashboard/dev/opportunities` and `/admin/opportunities`
   - Returns the created bid

2. **withdrawBidAction(bidId, opportunityId):**
   - Calls `withdrawBid(bidId)`
   - Revalidates paths
   - Returns void

3. **updateBidStatusAction(bidId, opportunityId, status, notes?):**
   - Admin only - calls `updateBidStatus(bidId, status, notes)`
   - Revalidates paths
   - Returns updated bid

Each action should follow the try/catch pattern with proper error re-throwing for client-side handling.
  </action>

  </verify>
  <done>bidActions.ts exports submitBidAction, withdrawBidAction, updateBidStatusAction with proper revalidation</done>
</task>
