<task type="auto">
  <name>Task 2: Add Loom URL field to BlueprintForm</name>
  <files>features/blueprints/components/BlueprintForm.tsx</files>
  <action>
Update BlueprintForm.tsx to add Loom video URL field:

1. Add imports:
   - `import { isValidLoomUrl } from '@/lib/utils/loom'`
   - `import { LoomVideoEmbed } from './LoomVideoEmbed'`
   - Add Video icon from lucide-react

2. Add state:
   - `const [loomUrl, setLoomUrl] = useState(blueprint?.loom_video_url || '')`

3. Add derived validation:
   - `const isValidLoom = !loomUrl || isValidLoomUrl(loomUrl)`

4. Update handleSubmit data object:
   - Add `loom_video_url: loomUrl || undefined` to the data object

5. Add new Card section AFTER "Basic Information" Card, BEFORE "Pricing Tiers" Card:
```tsx
{/* Loom Video */}
<Card>
  <CardHeader>
    <CardTitle className="flex items-center gap-2">
      <Video className="h-5 w-5" />
      Loom Video
    </CardTitle>
    <CardDescription>Add a Loom video walkthrough for this blueprint (optional)</CardDescription>
  </CardHeader>
  <CardContent className="space-y-4">
    <div className="space-y-2">
      <Label htmlFor="loomUrl">Loom Video URL</Label>
      <Input
        id="loomUrl"
        value={loomUrl}
        onChange={(e) => setLoomUrl(e.target.value)}
        placeholder="https://www.loom.com/share/..."
        className={!isValidLoom ? 'border-destructive' : ''}
      />
      {!isValidLoom && (
        <p className="text-sm text-destructive">
          Please enter a valid Loom URL (e.g., https://www.loom.com/share/abc123...)
        </p>
      )}
    </div>
    {loomUrl && isValidLoom && (
      <LoomVideoEmbed url={loomUrl} title={`${name || 'Blueprint'} walkthrough`} />
    )}
  </CardContent>
</Card>
```
