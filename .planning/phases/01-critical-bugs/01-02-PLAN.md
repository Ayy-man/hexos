Update the component to handle the new structured return type.

**Changes to make:**

1. Update `onStartNegotiation` prop type:
   ```typescript

   ```

2. Update `handleStart` function:
   ```typescript
   const handleStart = async () => {
     setIsLoading(true)
     try {
       const result = await onStartNegotiation()

       if (result.error) {
         // Show specific error message from server
         toast.error(result.error)
         return
       }

       if (result.deliverables && result.deliverables.length > 0) {
         toast.success(`Extracted ${result.deliverables.length} deliverables! Opening editor...`)
       } else {
         toast.info('No deliverables found in proposal. You can add them manually.')
       }

       router.refresh()
     } catch (error) {
       // Fallback for unexpected errors (network issues, etc.)
       console.error('Error starting negotiation:', error)
       toast.error('Failed to connect to server')
     } finally {
       setIsLoading(false)
     }
   }
   ```

**Key improvements:**
- Shows specific error message from AI parsing (e.g., "Proposal is empty or too short", "AI service error (429)")
- Distinguishes between "error" and "empty results"
- Only calls router.refresh() on non-error results
