  <name>Task 1: Create storage RLS migration</name>
  <files>supabase/migrations/20260119000001_general_purpose_storage_rls.sql</files>
  <action>
Create a new migration file that adds RLS policies to the `general-purpose` storage bucket.

**Policy requirements:**

1. **INSERT policy** - Authenticated users can upload to general-purpose bucket
   - `FOR INSERT TO authenticated`
   - `WITH CHECK (bucket_id = 'general-purpose')`
   - Use permissive policy (no folder restriction) because case studies use `case-studies/{timestamp}.ext` paths

2. **SELECT policy** - Public read access (bucket is already public)
   - `FOR SELECT TO public`
   - `USING (bucket_id = 'general-purpose')`

3. **UPDATE policy** - Authenticated users can update their uploads
   - `FOR UPDATE TO authenticated`
   - `USING (bucket_id = 'general-purpose')`

4. **DELETE policy** - Admin/Internal only
   - `FOR DELETE TO authenticated`
   - `USING (bucket_id = 'general-purpose' AND EXISTS (SELECT 1 FROM profiles WHERE profiles.id = auth.uid() AND profiles.role IN ('admin', 'internal')))`

**Important:**
- Use `DROP POLICY IF EXISTS` before each `CREATE POLICY` to make migration idempotent
- Follow naming convention from research: "Authenticated users upload to general-purpose", etc.
- Do NOT query the same table being protected (storage.objects) - only use auth.uid() and profiles table
- The bucket already exists and is public - do not recreate it
  </action>

  </verify>
